# KeeWebX v0.4.4

- Simplify the unlock screen with consistently sized password and passkey actions.
- Group optional key-file and passkey management in unlock options, with required key-file controls kept visible. Password recovery and cancellation of a pending unlock remain available.
- Keep passkey creation and verification behavior from v0.4.3, including retrying verification with the same credential.
- Keep remote synchronization notices clear of Settings navigation on short screens, and update multi-vault passkey checks for the explicit verification step.

New remains the default. Independent New, deprecated Classic and combined compatibility downloads are available as ZIP and TAR archives with checksums.
