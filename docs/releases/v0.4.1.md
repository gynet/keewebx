# KeeWebX v0.4.1

- Fix intermittent demo navigation failures in browsers with an existing service-worker cache. Redirected pages are cached as a redirect and a separate final document, and older affected entries are repaired when used. Demo links retain their automatic demo-opening behavior.
- Allow iPhone and iPad file pickers to select KDBX databases whose file type is not recognized by iOS. Desktop file filters remain available, and the database is still validated when opened.

The current interface remains the default. Classic is deprecated and retained at https://keewebx.app/classic and in the combined web archive. Existing encrypted vaults and pending edits are preserved.
