# KeeWebX 0.4.12

Local HTML now preserves WebDAV synchronization and configured external services.
The 0.4.11 local restrictions were too broad. Local files only block communication
with keewebx.app and its subdomains, and never check for application updates.
Website icons download directly instead of using the official app server.

The password generator's Advanced section, silent updates during unlocked
sessions, and movable Connect 0.6.12 App key remain available. Connect transport
and authorization are unchanged; the latest Userscript is still 0.6.12.

Download New (recommended), Classic (deprecated), or the combined compatibility
bundle. Extract the complete archive and verify its SHA-256 checksum.
