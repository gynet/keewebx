# KeeWebX v0.4.6

- Make an available registered passkey the primary unlock action. Password recovery stays one explicit switch away; required key files stay visible, and authentication errors reveal password recovery automatically.
- Keep the independent password generator under Tools on the start screen. Its keyboard shortcut and the unlocked vault toolbar remain available.
- Reveal the selected vault panel after opening another database, choosing a file, or connecting to storage, including on phone layouts. Existing open databases and unsaved edits remain in place.
- Open the full theme picker from the theme icon. Theme choices and system palette preferences stay synchronized with Settings.
- Use the configured website-icon service when downloading an entry icon, so installations with a service can fetch icons from sites that block direct browser requests. Downloads remain drafts until Apply.

New remains the default. Separate New and deprecated Classic ZIP/TAR packages, the combined compatibility archive, and checksums remain available.
