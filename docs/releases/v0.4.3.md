# KeeWebX v0.4.3

- Improve Settings on narrow touch screens: keep category navigation visible, retain the back button while scrolling, fit long labels and selects, and use touch-friendly controls and input text sizing.
- Separate local passkey creation from encryption verification. After creating a passkey, choose **Verify passkey** to finish setup. An interrupted verification can retry the same passkey instead of creating another credential. Canceling setup preserves the previous local registration and password recovery.
- Explain browser/provider refusal separately from incomplete verification. A provider must support WebAuthn PRF for encrypted local unlock; saving a normal passkey alone does not establish that support.
- Keep empty or incomplete file reads distinct from unsupported database formats in recovery checks.
- Download website icons inside the entry icon editor alongside built-in icons and image uploads. Preview the downloaded image and choose **Apply appearance** to save it; **Cancel** leaves the entry unchanged. The redundant entry-menu action has been removed.

New remains the default. Independent New and deprecated Classic downloads, together with the combined compatibility package, are available as ZIP and TAR archives with checksums. Deprecated Classic remains at https://keewebx.app/classic.
