# KeeWebX v0.4.0

The current interface is the default in the hosted app, demo, web downloads and development server. Classic is deprecated and retained at https://keewebx.app/classic and in the web archive’s explicit Classic HTML entries. Existing KDBX vaults keep their format and credentials.

- Edit entries, groups, protected fields, notes, templates, icons and colors; inspect and restore history and manage attachments.
- Open and work with multiple vaults, save to WebDAV, export encrypted backups, and recover from failed synchronization without discarding pending edits.
- Use compact entry actions, group menus and a shared mobile navigation panel. The bottom toolbar includes the password generator, settings and lock.
- Preview generated passwords directly, keep copy and reveal actions beside their fields, and use clipboard copy when native browser sharing is unavailable.
- Configure local passkeys and browser-extension permissions. Credential changes invalidate old quick-unlock data; existing credentials remain available for recovery.
- Preserve attachments and icons used by entries and history across every root group during database cleanup.

Download and extract the complete web ZIP or TAR archive. `index.html` opens the current interface; `classic.html` and `classic/index.html` retain deprecated Classic compatibility. Verify the accompanying SHA-256 checksum and keep all assets together.

A save in browser storage does not overwrite the original file selected from disk. Keep an independent encrypted backup. Passkey, clipboard and native-sharing availability depends on the browser and authenticator.
