# KeeWebX v0.4.2

Web downloads now offer independent interface packages:

- **New (recommended):** `keewebx-new-0.4.2.zip` or `.tar.gz`.
- **Classic (deprecated):** `keewebx-classic-0.4.2.zip` or `.tar.gz`.
- **Combined compatibility:** `keewebx-web-0.4.2.zip` or `.tar.gz`.

Each archive includes its own HTML, required assets, offline worker, license notices and deployment guide. Extract the complete archive and open `index.html`. Standalone packages omit the other interface's files and hide unavailable interface switches; the combined package retains both interfaces and switching. Existing KDBX databases need no conversion.

Every download includes a SHA-256 checksum. ZIP and TAR contents are compared after extraction and checked for startup, missing assets and script errors. Standalone downloads are also checked for offline startup with settings previously saved by the other interface.

Includes the v0.4.1 demo navigation and iOS database file-picker fixes. The hosted app continues to use New by default, with deprecated Classic at https://keewebx.app/classic.
