# Connect 0.6.18

Local connection recovery keeps the handshake available for up to one minute.
If the App needs to resume, visit the authorized App tab and return to the
website. The same request continues on return. Account queries and fills retain
their usual short deadlines. Closing the panel cancels the request.

The temporary connection page can report a setup failure when its transferred
port cannot. It verifies the original window and attempt before the website
acts on the failure. The optional local log records whether the helper opened,
responded, or reported an error. Logs stay on the device.
