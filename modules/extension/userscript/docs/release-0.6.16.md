# Connect 0.6.16

The Connection panel offers an optional Connection log in the App and on login
websites. Enable it in both tabs before reproducing a problem, then copy each
log manually. Recording is off by default and retains only the last 120 events
in that tab's memory. Reloading or disabling it clears the log. The log omits
website addresses, account data and credentials. It sends no requests.

This release includes the recovery fixes in [0.6.15](release-0.6.15.md). Update
one existing script and reload the App and the login website after saving any
pending edits.
