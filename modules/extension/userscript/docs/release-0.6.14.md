# Connect 0.6.14

If the original App does not answer worker discovery, Connect checks that the
saved authorization still points to the same App and tries the existing signed,
encrypted local Userscripts mailbox. A successful fallback can be reused in that
website document for two minutes. Explicit reconnect can try MessagePort again.
Only the original App and its existing account permissions apply. The fallback
requires the App to execute and the manager to deliver local storage events.

Update the existing userscript and reload KeeWebX and the login website after
saving pending edits.
